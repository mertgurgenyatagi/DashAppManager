DashAppManager - Windows Application
=====================================

This folder contains the complete DashAppManager application.

To run the application:
- Double-click DashAppManagerWPF.exe

What's included:
- DashAppManagerWPF.exe - Main application executable
- dashapp_logo.png - Application logo
- profiles.csv - Profile data
- projects.csv - Project data  
- completed_tasks.txt - Task completion tracking
- Various .NET runtime files required for the application

System Requirements:
- Windows 10 or later
- No additional software installation required (self-contained)

The application will automatically create and manage additional data files as needed.
